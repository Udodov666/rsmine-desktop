# RSMine — приложение стримера

Локальная программа для Windows: принимает донаты через LZT Market, показывает алерты в OBS, озвучивает сообщения (Cartesia) и запускает визуальные эффекты. Панель управления — на сайте [rsmine.ru](https://rsmine.ru), программа — связующее звено между сайтом и стримом.

## Установка

1. Скачайте `RSMine-Setup-1.3.1.exe` по ссылке выше.
2. Если Windows покажет синее окно **SmartScreen** («Система Windows защитила компьютер») — нажмите **Подробнее → Выполнить в любом случае**. Это стандартное предупреждение для приложений без платной цифровой подписи; исходный код открыт, можете собрать сами (см. ниже).
3. Пройдите установку (можно выбрать папку) — на рабочем столе появится ярлык RSMine.

## Настройка (5 минут)

Запустите программу и заполните поля:

| Поле | Где взять |
|---|---|
| **Slug** | Ваш адрес доната на rsmine.ru: `rsmine.ru/d/<slug>` — то, что вместо `<slug>` |
| **App Secret** | Настройки → Основные на сайте (кнопка «Показать») |
| **LZT-токен** | [lztnet API](https://lztnet.com) → профиль → API-ключи (токен с правами Invoice) |
| **Merchant ID** | LZT Market → настройки продавца |
| **Cartesia API key** *(необязательно)* | [play.cartesia.ai](https://play.cartesia.ai) → API Keys — для нейро-озвучки донатов |

Все ключи хранятся только на вашем компьютере в защищённом хранилище Windows (DPAPI) и никуда не отправляются, кроме API-запросов к сервисам выше.

## Подключение к OBS

1. В программе откройте вкладку **Оверлей** и скопируйте URL.
2. В OBS: **Источники → + → Браузер** → вставьте URL → ширина 1920, высота 1080 → OK.
3. Готово: алерты, полоса цели и эффекты появятся в сцене.

## Что умеет

- **Донаты в реальном времени** — алерт с гифкой, заголовком и сообщением.
- **Озвучка** — 9 русских голосов Cartesia, голос выбирает донатер.
- **Эффекты** — конфетти, сердечки, вспышка.
- **Полоса цели сбора** — прогресс обновляется автоматически.
- **Фильтр слов** — мат и ссылки маскируются в алерте и озвучке.
- **Журнал сообщений** — повторить донат в эфире или скрыть его одним кликом.
- **Автостарт** с Windows (отключается в настройках программы).

## Сборка из исходников (для разработчиков)

```bash
git clone https://github.com/jdankinloh/rsmine-desktop
cd rsmine-desktop
npm install
npm start        # запуск без сборки
npm run dist     # сборка установщика в dist/
```

Стек: Electron 33, TypeScript-less main process, ws. Сборка релизов автоматическая (GitHub Actions, тег `v*`).
