RSMine —
Аккаунт
Связь программы с твоим аккаунтом RSMine. Секрет — из панели: Подключение → шаг 1.
Тот же ник, что на Twitch — он же в ссылке твоей страницы доната.
Вводится звёздочками. Даёт программе право соединяться с твоим аккаунтом; на сервере — только хеш. Пересоздать можно на сайте: Подключение → шаг 1.
Платежи
Счёт зрителю создаёт программа: LZT-токен не покидает этот компьютер.
Озвучка
Ключ Cartesia для голосовых алертов. Где взять: play.cartesia.ai → API Keys → Create API key.
Ключ уходит только на сервер RSMine и используется для синтеза алертов.
Программа
Сервер API обычно менять не нужно. Автозапуск включает программу вместе с Windows.
Запускать вместе с Windows
